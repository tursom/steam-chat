## 预览

```sh
python3 -m http.server 18351 --directory web
```

打开 `http://localhost:18351/redesign-prototype/`。

底部工具栏可以切换：

- 身份：超级管理员 / 客服 / 审计员；
- 页面；
- 手机预览；
- 主题；
- Steam 在线 / 离线；
- 存储告警；
- 拖入图片。

URL 参数：

| 参数 | 取值 |
| --- | --- |
| `as` | `admin` / `cs` / `auditor` |
| `page` | `chat` / `accounts` / `users` / `roles` / `audit` / `emotes` / `settings` / `login` |
| `theme` | `light` / `dark` |
| `phone` | `1` |
| `thread` | `1`（手机预览时直接进入会话） |
| `utab` | `overview` / `perm` / `grant` / `sessions` |

和之前的原型一样，本目录不进生产构建（`scripts/build-web.cjs` 只复制明确列出的文件）。

## 值得看的状态

- **三个身份**：
  - 客服：聊天级授权，3 位指定好友，个人授予 `emote.manage`；
  - 审计员：只读，全部会话；
  - 超级管理员。

  切换后可以对比会话列表、输入区、表情弹层和控制台导航。
- **发送状态**：「林间晚风」最后一条为发送失败；「Morrow」里有「结果未确认」和「图片上传超时重试」。
- **输入区**：
  - 「添加图片」生成待发送缩略图；
  - 发送后出现上传进度；
  - 工具栏「拖入图片」显示拖放覆盖层。
- **会话列表**：会话右键打开上下文菜单。
- **用户**：
  - 「用户 → 客服一号 → Steam 授权」：分级、指定好友、有效期；
  - 「权限」标签：个人覆盖。

  修改后出现「未保存的更改」条。
- **角色与权限**：「按角色」和「权限对照表」两种视图。
- **审计日志**：点开一条显示字段级差异。
- **Steam 账户 → 添加账户**：扫码和密码登录两个标签，以及 Steam Guard 验证码。
- **快速跳转**：Ctrl K。

## 范围

原型只有界面，没有后端通信：

- 所有好友、消息、用户、审计记录都是模拟数据，刷新后重置；
- 二维码是示意图，不能扫。

素材来源：

- 图标沿用 `../prototype/assets/` 的 Lucide 0.468.0（ISC）和三张游戏封面；
- 表情图沿用 `../android-prototype/assets/`。
