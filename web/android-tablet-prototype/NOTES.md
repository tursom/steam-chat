# Steam Chat 安卓平板交互原型

状态：用户已确认的设计参考。沿用现有 A 方向的浅色、绿色视觉，设计重点是横屏平板上的会话切换、阅读与输入。原生 Android 0.1.10 已按此方案实现响应式布局与状态保留，详见 [Android 说明](../../android/README.md)。本目录继续作为独立交互演示，使用内存中的模拟数据。

## 预览

在仓库根目录启动静态服务：

```sh
python3 -m http.server 18350 --directory web
```

打开 `http://localhost:18350/android-tablet-prototype/`，也可直接打开本目录的 `index.html`。运行中的局域网预览为 `http://dev.lan:18350/android-tablet-prototype/`。

- 默认展示横屏，可在顶部切换小平板、竖屏、分屏和手机尺寸。
- “沉浸预览”让应用铺满当前浏览器视口；顶部状态栏中间可退出，也支持 Esc。
- `?immersive=1`：按浏览器实际视口展示。
- `?details=1`：初始打开好友资料。
- `?device=compact|portrait|split|phone`：指定初始预览尺寸。
- 底部演示工具可模拟来信、网络断开/恢复及屏幕键盘。

## 布局方案

按**可用窗口宽度**适配，而不是通过设备型号或方向直接判断。网页 CSS 像素用于设计验证，原生实现阶段应映射为 dp。

| 可用宽度 | 布局 | 好友资料 |
| --- | --- | --- |
| ≥ 1200 | 74px 导航栏 + 约 300px 会话栏 + 弹性聊天区 | 按需展开约 270px 侧栏，与聊天并排 |
| 840–1199 | 68px 导航栏 + 280px 会话栏 + 弹性聊天区 | 覆盖式抽屉，保留聊天区宽度 |
| 600–839 | 导航栏 + 会话列表/聊天单栏切换 | 覆盖式抽屉 |
| < 600 | 会话列表使用底部导航；进入聊天后显示返回按钮 | 覆盖式抽屉 |

主视图默认收起好友资料，将空间留给聊天。消息阅读区域最大约 760px；宽屏不会把气泡拉成整行。导航、会话列表、聊天头部和输入区固定在各自区域，列表与聊天记录独立滚动。

横竖屏/窗口调整保留当前会话、草稿和附件。屏幕键盘打开后，布局可用高度减少，列表和历史区域继续滚动，输入区保持可见。可用高度不足时压缩键盘、聊天头和输入留白，暂时收起会话栏的搜索/筛选，让发送和图片操作保持可点击。切换主导航、返回列表或打开好友资料时收起模拟键盘。当前聊天从单栏列表或设置恢复可见时按打开即已读处理。

## 可操作内容

- 会话/好友切换、搜索、未读筛选、选中态及未读数变化。
- 各个会话独立保存文字草稿、待发送图片与滚动位置，保存在当前页面内存中。
- 文字发送、Enter 发送、Shift + Enter 换行；中文输入法组合输入不触发误发送。
- 两个本地 Steam 表情及 Emoji 选择。此原型尚未演示真实贴纸库存。
- 本地图片选择、预览、移除、发送与大图查看；图片通过 object URL 在浏览器中显示，不上传。
- 好友资料的并排栏/抽屉、Steam ID 复制；抽屉支持 Esc、遮罩关闭与键盘焦点约束。
- “查看更早的消息”插入两条演示历史并保持阅读位置。
- 查看历史时模拟来信不会强制跳到底部，显示“有新消息”按钮；发送自己的消息会定位到底部。
- 断网演示保留草稿、停用发送；来信暂存，恢复连接后补入当前页面。
- 设置页的三个通知开关保留本次页面内的选择，不修改真实系统设置。

## 范围与资源

这是一份布局与交互原型，不包含后端通信、真实 Steam 登录、系统通知、实际 Android IME 或持久化数据库。所有好友、消息、在线状态与时间均为演示数据；刷新页面会重置。不会调用实际发送接口。

模拟键盘用于检查空间分配，不能代替原生软键盘、旋转、多窗口与系统手势的真机验收。普通 B站链接示例展示当前 App 的 av 链接形式，原型不执行短链网络解析。

沿用 `../prototype/assets/` 的 Lucide 0.468.0（ISC）及三个 Steam 游戏封面，沿用 `../android-prototype/assets/` 的两个 Steam 表情。头像为 CSS 图形/字母。所有资源从本地静态目录加载，无第三方字体或图片请求。

原型位于独立目录，生产 Web 构建的显式复制清单不会打包它。
