# B 站视频链接播放

普通链接、`[url]` BBCode 和 Steam OpenGraph 预览卡片中的 B 站视频会显示「播放 B 站视频」按钮。支持 bilibili.com、www.bilibili.com、m.bilibili.com 的 BV/av 视频地址，保留 `p` 分 P 编号；也支持 b23.tv 分享短链接。直播、动态、番剧等非普通视频链接不在本次支持范围内。

点击后嵌入 `https://player.bilibili.com/player.html` 官方播放器，依据视频 ID 和分 P 编号重新构造参数，固定 `autoplay=0`，不自动播放。支持官方播放器的全屏操作，始终保留原链接和关闭按钮。发送消息及其回显沿用增量渲染，保留已有 iframe 状态；关闭播放器或切换会话时移除 iframe。具体视频仍受 B 站版权、登录、地区和外链播放规则限制，无法播放时可打开原视频。

短链接只在点击时调用 `GET /api/bilibili/resolve?url=...`。接口要求后台会话及 `chat.use` 权限，Steam 离线也可使用；异步完成后再次检查权限，返回 `private, no-store`。后端只请求固定 B 站短链域名，逐跳校验目标，只跟随最多 5 次跳转，总超时 8 秒。只读取跳转头并取消响应正文，不转发用户 Cookie，也不下载或代理视频。非视频链接、网络错误及不支持的跳转均显示原链接回退，不自动重试。

浏览器收到短链解析响应后重新校验官方视频 URL；会话/账号已经切换或播放卡片已移除时，迟到结果不能创建播放器。跨域限制使网页无法可靠读取 B 站播放器内部的错误，因此不会把 iframe 加载成功当成音视频已播放的确认。

验证：`npm test` 覆盖链接格式、分 P、跳转边界、错误、会话权限及异步权限变化。构建后 `node test/browser/bilibili-player.cjs`（需 Playwright Chromium）覆盖桌面/手机视口、普通/预览/BBCode 链接、点击加载、参数、关闭、错误回退、发送期间 iframe 保留及迟到响应隔离。此浏览器回归使用模拟 iframe；真实官方播放器和公开分享链接另行只读验证，未向好友发送测试消息。
