# Steam 登录超时自动恢复

生产入口使用可替换的 Steam SDK 客户端。单次登录超过 120 秒未完成时，停止使用该实例，并按 5、10、20、40、80、160、300 秒的间隔重试，后续间隔保持 300 秒。每次超时后的重试都会创建新实例，使用保存的 refresh token，不在可能仍有异步认证任务的旧实例上再次调用 logOn。

后台等待期间显示 reconnecting，登录尝试期间显示 logging_in。成功登录后退避重置为 5 秒。无保存凭据时回到 logged_out；验证码等待不计入登录超时，凭据无效等终止错误不会无限重试。退出登录和停止服务会取消计时器。

应用持有稳定客户端引用，消息和登录监听器在更换实例后继续有效；旧实例迟到的消息、refresh token、网页会话和错误事件不会转发到应用。旧实例若迟到登录成功，会再次被要求退出。

恢复只重建 Steam 连接，不重启 HTTP 服务，不自动重发失败或结果不明的聊天消息。嵌入式调用方若直接提供不可替换客户端且没有配置 replaceClient，则仍保留超时后拒绝复用的保护。

验证见 test/steam-timeout-recovery.test.ts：指数退避及上限、成功后重置、新旧事件隔离、停止时取消、Guard 等待、凭据失败，以及安装的真实 SDK 的客户端替换。
